Lista de los usuarios de GitHub más activos según sus `contribuciones públicas`, `contribuciones privadas` y `número de seguidores`, organizados por ciudad.

La lista se actualizó el `16/08/2026 9:29 PM UTC`.

Este repositorio contiene datos de **7 ciudades**.

Para aparecer en la lista se necesita un número mínimo de seguidores, que varía según la ciudad. Ese mínimo se puede consultar en [config.json](https://github.com/NachoOFC/top-github-users-chile/blob/main/config.json).

Este proyecto está basado en la acción de GitHub [gayanvoice/top-github-users-action](https://github.com/gayanvoice/top-github-users-action).
